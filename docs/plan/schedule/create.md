# 방 생성 — 기획 상세

> Screen 1: `/schedule/new`

---

## 1. 화면 목적

생성자가 팀 이름, 본인 닉네임, 조율할 날짜/시간 범위, 팀 정원을 입력하여 팀을 생성한다.
생성 완료 후 공유 링크를 얻어 참여자를 초대할 수 있다.

---

## 2. UI 요소 및 동작

### 2-1. 방 이름 (필수)

- 텍스트 입력 필드
- 최대 글자수: 20자
- 플레이스홀더 예시: "있지 걸스윌비걸스"
- 유효성 검사: 공백만 입력 시 오류

### 2-2. 닉네임 (필수)

- 생성자 본인이 참여자 목록에 표시될 이름
- 최대 글자수: 5자
- 유효성 검사: 공백만 입력 시 오류

### 2-3. 날짜 선택 (필수)

- 달력 UI로 복수 날짜 선택
- 선택 가능 날짜 수: 제한 없음
- 최소 1개 이상 선택해야 방 생성 가능
- **요일 헤더 클릭으로 일괄 선택**: 달력 상단의 요일(일/월/화/수/목/금/토) 클릭 시 해당 월에 속한 모든 해당 요일 날짜를 일괄 선택
  - 해당 요일 날짜가 모두 선택된 상태에서 다시 클릭하면 전체 해제
  - 일부만 선택된 상태에서 클릭하면 전체 선택

### 2-4. 시간 범위 (필수)

- 하루 중 조율 대상 시간 구간
- 시작 시각: 0~23시 선택, 기본값 08시
- 종료 시각: 1~24시 선택, 기본값 23시
- 유효성 검사: 종료 시각 > 시작 시각이어야 함

### 2-5. 팀 정원 (필수)

- 팀의 고정 멤버 수 입력 (팀 전원이 일정 조율에 참여)
- 입력 범위: 2~25
- 역할:
  - 결과 화면에서 "N명 중 M명 제출" 형식으로 표시
  - **팀 전원 제출 완료 시 방이 자동으로 closed 상태로 변경**
- 유효성 검사: 범위 외 값 입력 시 오류

### 2-6. [방 만들기] 버튼

- 모든 필드 유효성 통과 후 방 생성 API 호출
- 생성 중 버튼 비활성화 + 로딩 표시
- 생성 완료 시:
  1. 생성자 UUID 발급 → 쿠키(`schedule_{id}`)에 저장
  2. `/schedule/[id]/availability`로 이동

## 3. 유효성 검사 목록

| 필드      | 조건                | 오류 메시지                            |
| --------- | ------------------- | -------------------------------------- |
| 방 이름   | 비어 있거나 공백만  | "방 이름을 입력해주세요."              |
| 닉네임    | 비어 있거나 공백만  | "닉네임을 입력해주세요."               |
| 날짜      | 선택된 날짜 0개     | "날짜를 하나 이상 선택해주세요."       |
| 시간 범위 | 종료 ≤ 시작         | "종료 시각은 시작 시각보다 커야 해요." |
| 인원수    | 범위 외 또는 미입력 | "인원수를 입력해주세요."               |

오류 메시지는 해당 필드 바로 아래 인라인으로 표시.

## 4. API 호출

**POST `/api/schedules`**

```json
Request:
{
  "title": "팀 회식 날짜 조율",
  "nickname": "홍길동",
  "dateList": ["2026-05-25", "2026-05-26"],
  "timeRangeStart": 8,
  "timeRangeEnd": 22,
  "memberCount": 5
}

Response 201:
{
  "schedule": { "id": "abc1234xyz", ... },
  "member": { "id": "uuid-...", "nickname": "홍길동", "role": "leader", ... }
}
```
